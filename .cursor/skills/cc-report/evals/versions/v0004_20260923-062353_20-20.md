# CC Report (v1.3) — CC Relay reverse hop

Changelog: v1.3 — binary evals (`evals/`) + trigger fixtures + overnight loop; pushier description; Output Contract requires `Do not:`. v1.2 — **paste bridge**: ACK must end with `PASTE INTO CLAUDE CODE` fence (operator blind-pastes). Retired Cursor-only ACK. v1.1 — renamed skill to `cc-report`; umbrella **CC Relay**. v1.0 — durable markdown reverse report.

## Purpose

- Close the **CC Relay** loop without pasting Claude Code’s Terminal UI into Cursor.
- Claude Code writes a structured **`_report.md`** under a shared directory; Cursor reads it and cross-checks git.
- Keep phase gates: no Phase N+1 / push until Cursor ACKs the report.
- Operator **blind-pastes** Cursor ACK into Claude Code — see always-on rule `.cursor/rules/tbcc-cc-paste-bridge.mdc`.

## CC Relay family (Cursor ↔ Claude Code)

| Hop | Slash | Skill |
|-----|-------|-------|
| Pack forward | `/directive` | `directive-generator` |
| Lane C pack | `/handoff-cc` | `handoff-claude-code` |
| **Execute (in Claude Code)** | **`/cc-run`** | **`tbcc-cc-run`** |
| **Reverse (this)** | **`/cc-report`** | **`cc-report`** |
| Next after ACK | `/continue-thread` | `tbcc-continue-thread` |

**Paste bridge:** Cursor ACK **must** include a fenced `PASTE INTO CLAUDE CODE` block. Claude Code phase STOPs **must** include `PASTE INTO CURSOR` (or the operator pastes `/cc-report` + report path). Disk `*_report.md` remains source of truth for review.

- Trigger phrases: `/cc-report`, `read the CC report`, `Claude Code report`, `reverse handoff`, `review Claude Code completion`
- Deprecated alias (still match once): `/claude-code-report` → treat as `/cc-report`
- Situational triggers:
  - User returns from Claude Code after a handoff phase (often by pasting CC’s `PASTE INTO CURSOR` fence)
  - Building a forward `/handoff-cc` — inject reverse-report + paste-bridge into Working agreement
  - Bottom line after Lane C work without a report file yet

## Execution Profile

- Mode: **Agent** (read/write report artifacts; do not implement next phase unless user explicitly continues **or** the paste fence’s `Do:` names a Cursor-side action only)
- Model lane: **Lane A (Desktop Auto)** for review; prefer cheap verify over re-planning
- Parallelism: none required; optional cheap explore only if report path is ambiguous
- Mode inheritance: n/a

## Delegation & Tooling

- Skills: `handoff-claude-code` (forward), `tbcc-continue-thread` (after ACK), `model-routing`
- Rules: `.cursor/rules/tbcc-cc-paste-bridge.mdc` (always on)
- Paths: `tbcc/docs/handoffs/`
- Git: `git log` / `git show --stat` / `git status` to verify report claims
- MCP: none

## Behavioral Rules

- Reason by: **file + git are source of truth**; TUI paste is last resort
- Avoid:
  - Asking the user to paste full Claude Code transcripts
  - Starting Phase N+1, push, or live bot Start from a report alone (put those in the paste fence’s `Do:` for Claude, or wait)
  - Committing `.env`, `.tbcc-run/`, `*.session*`
  - Human-only ACK prose with **no** `PASTE INTO CLAUDE CODE` fence on multiphase work
- Prioritize:
  - Locate latest matching `*_report.md`
  - Cross-check commit hashes and verification claims
  - Clear **go / fix / wait** verdict **inside** the paste fence

## Cursor procedures

### A) Emit paste-ready instruction for Claude Code

When user asks how Claude should report back (or when finishing a forward handoff), output a **single fenced block** they can paste into Claude Code:

```
PASTE INTO CLAUDE CODE
Write a reverse handoff for Cursor review to:

tbcc/docs/handoffs/YYYY-MM-DD_<topic>_report.md

Use this structure (markdown only, no chat fluff):

# Reverse handoff — <topic>
- Branch:
- Head commit(s) this phase (hash + subject):
- Status: Phase N complete | blocked | needs Cursor review

## Done
- Bullets of what shipped (behavior, not file trivia)

## Files touched
- path — one-line why

## Verification run
- Exact commands + pass/fail results (short output)

## Risks / open questions
- Anything Cursor must confirm before Phase N+1 or merge

## Do not
- push / start bots / touch .env / Phase N+1 until Cursor ACK

Then STOP. End your chat reply with a PASTE INTO CURSOR fence naming /cc-report and this report path.
```

### B) Review an existing report

1. Resolve path: user-named file, or newest `tbcc/docs/handoffs/*_report.md` matching the branch topic.
2. Read the report.
3. Verify with git (`log` vs claimed commits, `show --stat` vs Files touched, working-tree dirty unrelated files).
4. Reply with:
   - One short plain line for the human
   - **Required fence** `PASTE INTO CLAUDE CODE` containing:
     - `Verdict:` ACK — go Phase N | ACK — directive complete | fix | wait
     - `Report:` path
     - `Do:` / `Do not:` for Claude Code
   - Optional Gaps / Tray smoke **after** the fence (operator may ignore)
5. Do not start the next implementation phase in Cursor unless the user explicitly asks after ACK; put Claude’s next grind in the paste fence.

## Output Contract

- When emitting for Claude: fenced `PASTE INTO CLAUDE CODE` block + report path
- When reviewing: plain one-liner + paste fence with **all four** lines:
  - `Verdict:` ACK — go Phase N | ACK — directive complete | fix | wait
  - `Report:` path (or explicit missing)
  - `Do:` next Claude actions
  - `Do not:` push / start bots / touch `.env` / Phase N+1 unless listed
- Never use a Cursor-only ACK. Never push or start bots from a report alone.
- Done means: report path exists (write case) or reviewed against git (read case) **and** paste fence present on multiphase ACK
- Artifacts: `tbcc/docs/handoffs/YYYY-MM-DD_<topic>_report.md`
- Failure contract: if no report and no topic, ask one question (topic stem / path) — do not invent a review from TUI paste alone
- Self-check: `evals/program.md`
  - `py -3.13 -m tools.skill_gap.improve_once --skill cc-report`
  - Overnight: `py -3.13 -m tools.skill_gap.overnight_loop --skill cc-report --until-perfect`

## Exit Conditions

- After paste instruction → user blind-pastes into Claude Code → CC runs → returns with `PASTE INTO CURSOR` or `/cc-report`
- After review → user blind-pastes ACK fence into Claude Code → next phase or stop
- Composes: → `continue-thread` | `directive-generator`
